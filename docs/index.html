// NETWORK MODES

One browser, three routes.

Switch routes from the toolbar. DarkBrowser manages local Tor and I2P services, gives each its status, and recognizes `.onion` and `.i2p` addresses.

Tor

Route traffic through a local SOCKS proxy and browse supported `.onion` sites.

I2P

Use a local I2P HTTP proxy to visit services on the I2P network.

Clear

Use a normal direct connection when privacy routing is not required.

// BUILD FROM SOURCE

Build it yourself.

DarkBrowser packages as AppImage, Debian, and RPM formats on Linux x86_64. Arch users can use the portable AppImage.

npm ci
npm run setup
npm run build
DarkBrowser is experimental software and is not a replacement for hardened anonymity tools such as Tor Browser.
